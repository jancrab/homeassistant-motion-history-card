# Changelog

## 0.1.0 — 2026-10-29

- First standalone Motion History Card release, replacing a tile/history composition without requiring mod-card, layout-card or card-mod.
- Compact aligned room tiles and one-hour recorded history, updated every 30 seconds by default.
- Configurable sensors, room names, icons, colors, order, history duration and refresh interval.
- Native more-info actions, keyboard controls, English/German labels and theme support.
- Missing data, stale history and errors remain explicit. Polling pauses offscreen; requests cannot overwrite newer configurations.
- Locally bundled runtime, visual editor, automated tests, simulated preview and HACS release packaging.
