# Motion History Card v0.1.0

First independent release for compact room activity and recorded motion history.

- Room tiles and aligned timeline in a single card, without mod-card, layout-card or card-mod.
- Defaults: one hour of history, refresh every 30 seconds, 52 px rows and cyan/yellow/pink room colors.
- More-info on touch or keyboard activation. Visual editor for sensors, names, icons, colors, order and timing.
- English/German text, theme colors, narrow-card layout and reduced motion.
- Explicit missing/offline history and safe request cleanup.

Install as a custom **Dashboard** repository in HACS, or download the JavaScript asset and register it as a module. Configuration examples are in the README. Requires HA history/recorder data for the configured binary sensors.

Automated tests and browser previews use simulated HA data. Real HA installation, native editor startup and recorder permissions still need verification on the target instance.
